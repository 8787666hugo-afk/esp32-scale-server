# 郊狼 (DG-LAB Coyote 3.0) 波形

| 檔案 | 名稱 | 說明 | 長度 |
|---|---|---|---|
| `01_staircase.json` | 階梯漸強 | 實心階梯 20→40→60→80→100%，頂端停 0.6 秒後休息 0.6 秒 | 2.0 秒 |
| `02_stepped_peaks.json` | 階梯波峰 | 20ms 脈衝，階梯升到 100% 再降到 60%，停 0.2 秒 | 1.3 秒 |
| `03_frequency_sweep.json` | 頻率漸快 | 強度 100%，脈衝週期 80ms→10ms 漸密，再實心 1.2 秒 | 2.4 秒 |

`all_waveforms.json` 把三個波形放在同一個檔案裡。`.svg` 是預覽圖。

## 格式

`pulseData` 是 V3 協議的波形陣列，每個 HEX 字串代表 100ms：
前 4 byte 是 4 個 25ms 的頻率值 (10~240)，後 4 byte 是強度 (0~100%)。
例如 `0A0A0A0A64646464` = 頻率 10、強度 100%。

可直接用在 DG-LAB 官方 Socket 協議 (`pulse-A:[...]`) 或其他接受 V3 HEX 波形陣列的工具。
強度是相對於你在 App 上設定的通道強度的百分比，請從低強度開始試。

## 修改

改 `generate.py` 裡的數值後執行 `python3 generate.py` 重新產生。
